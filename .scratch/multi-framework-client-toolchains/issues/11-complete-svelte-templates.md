**What to build:** Svelte authors can select every supported Sporades template and receive an idiomatic Svelte Capsule with the same externally visible workflows as its existing React counterpart.

**Blocked by:** 10 — Admit Svelte with native stores.

**Status:** ready-for-agent

- [ ] Guestbook, Photo Library, and Campfire scaffolds are available for Svelte with admitted dependencies and immediately runnable project configuration.
- [ ] Each scaffold uses Svelte-native components and stores for its query, mutation, auth, preferences, Files, App-message, and Journey behavior.
- [ ] Generated HTML, styles, imported assets, TypeScript settings, README, and agent instructions agree with the Svelte/Vite contract.
- [ ] Every scaffold builds into the normalized public tree and starts in a Dev session without manual repair.
- [ ] Focused runtime tests prove each template's defining public behavior and deterministic store cleanup.
- [ ] The Svelte template set crosses the Container and Hosted release contract through the shared conformance fixtures.
