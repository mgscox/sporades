# 09 — Complete Vue template parity

**What to build:** Vue authors can select every supported Sporades template and receive an idiomatic Vue Capsule with the same externally visible workflows as its existing React counterpart.

**Blocked by:** 08 — Admit Vue with native composables.

**Status:** ready-for-agent

- [ ] Guestbook, Photo Library, and Campfire scaffolds are available for Vue and install only the admitted Vue/Vite and template dependencies.
- [ ] Each scaffold expresses its UI, reactivity, auth, Files, App-message, preferences, and Journey behavior through Vue-native patterns rather than translated React hooks.
- [ ] Generated HTML, styles, imported assets, TypeScript settings, README, and agent instructions agree with the Vue/Vite contract.
- [ ] Each scaffold builds through the normalized public tree and starts in a Dev session without manual source edits.
- [ ] Focused runtime tests prove the defining behavior of each template, including authenticated private Files and consented Journey activity where applicable.
- [ ] The Vue template set crosses the Container and Hosted release contract through shared conformance fixtures without toolchain-specific release exceptions.
