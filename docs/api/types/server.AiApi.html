    Type Alias AiApi

    Server-only, provider-neutral client for the OpenAI-compatible endpoint configured in sporades.json ai (Chat Completions or Responses). Calls never throw and never retry, so callers can fail open. Prompt and response content is never logged; each call emits one ai.call metering event with model, token counts, latency, and outcome.
